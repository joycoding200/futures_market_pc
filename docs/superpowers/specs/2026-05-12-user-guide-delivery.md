# 用户使用说明 — 交付规划

> 日期：2026-05-12 | 状态：已规划

## 1. 概述

原始需求明确要求交付"简单使用说明"。需编写面向最终用户的简明操作手册，涵盖软件的核心功能操作流程。

## 2. 交付物

### 2.1 README.md（项目根目录）

面向用户的快速入门指南，包含：

**结构大纲：**

```markdown
# 期货行情PC软件

## 快速开始
- 系统要求（Windows 10+, Qt 6.x 运行时）
- 构建与运行（cmake --build .）
- 首次启动说明

## 主要功能
### 行情查看
- 合约列表：点击切换合约，搜索框过滤，交易所筛选
- K线图：滚轮缩放、拖拽平移、周期切换（1m/5m/15m/30m/1H/D）
- 分时图：实时价格走势 + 均价线
- 盘口面板：五档买卖盘实时更新

### 技术指标
- MA均线：叠加在K线主图上（MA5/MA10/MA20/MA60）
- MACD/KDJ/RSI：切换副图查看
- 指标参数可调

### 数据统计
- 涨幅榜/跌幅榜/成交量排行
- 成交量分布（大/中/小单统计）

### 数据源切换
- 系统设置 → 数据源标签页 → 选择 Sim/CTP
- CTP 需配置 BrokerID + 行情地址

## 配置说明
- 设置文件位置：QSettings 自动管理
- 可配置项：刷新间隔、K线数量、模拟价格等

## 常见问题
- Q: 启动无数据 → 检查是否订阅了合约（合约管理）
- Q: CTP连接失败 → 检查BrokerID和地址配置
- Q: K线图无数据 → 等待数据累积，或切换数据源
```
